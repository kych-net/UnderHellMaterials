# 怪动植物 3D 模型生成提示词(全细节版)

平台:`https://3d.hunyuan.tencent.com`(腾讯混元 3D)。依据 `文档/内容/生物/怪动植物.typ`。

## 平台规则(直接决定怎么写)

- 官方格式:`{量词}+{主体},{详细描述},{风格}`。单条提示词上限约 1024 字符。
- 不要写 negative prompt、4k、8k 这类生图套路词。
- 不写绝对尺寸。3D 只吃比例,把"7m 翼展 / 2m 身高"改写成"翼展约为身体高度的 3.5 倍"。
- 多视图输入远准于文生。`图片/怪动植物三视图.svg` 导出的正/侧/背位图就是多视图素材。
- 人形 T-pose / A-pose 可自动绑骨(Mixamo 兼容)。

## 几何与纹理分开生成(推荐)

平台原生支持两段式。API 参数 `GenerateType`:

| 值 | 输出 |
|---|---|
| `Normal` | 几何 + 纹理,一次出 |
| `Geometry` | 只出几何白模,无纹理,仅输出 GLB,更快 |
| `Texture` | 只出纹理,需传 `MeshUrl`(已有 .glb / .obj) |

网页端对应工作台的"几何生成 → 纹理绘制"两步,纹理可用文生纹理或图生纹理。

对怪动植物格外合适:本体造型本就全白,几何阶段的白模几乎就是成品配色,不必靠纹理遮盖几何缺陷。

## 完整流程

1. 几何:多视图生 3D,`GenerateType=Geometry`。输入用三视图导出的正/侧/背 PNG,提示词用 A。得到白模 GLB。
2. 分件生成 B、C、D、E,同样只出几何。
3. Blender 组装与修正:拼接各件;补 3D 生不出的项——侧线沿体侧建工字形截面曲线挤出,金属丝用细圆柱;翼展按 3.5 : 1 拉到设定值;面数过高用"智能拓扑"减面。
4. 纹理:修好的模型导出 GLB,回传 `MeshUrl`,`GenerateType=Texture`,文生纹理描述填:

哑光纯白表面,细密的浅青色表层血管网,颅顶略带骨质光泽,体侧一对银灰色金属丝有金属质感,柔和不反光。

几何错了重生成几何,不用重做纹理;纹理不满意重做纹理,不动几何。

## 已知限制

- 超细长结构(细长翼、感知线、金属丝)3D 生成普遍不稳,会被截短、塌成薄片或直接丢失。
- 截面信息(工字形侧线)文生 3D 无法表达,必须多视图或手工建模。
- 材质级细节(骨质颅顶、血管网、气凝胶触感层)落在贴图上,不在几何上。
- 若提示词被内容审核拦截,把"连体紧身服"改为"哑光白色一体式装备外壳",增强装备感。
